## Projects

- **[Chrona](https://github.com/Abpattar/Chrona)** — local-first Android planner built with Kotlin and Jetpack Compose.
- **[GestureOS](https://github.com/Abpattar/GestureOS)** — Python webcam app for controlling desktop actions with hand gestures.
